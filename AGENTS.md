# NetBSD Kernel Development & AI Assistant Guidelines

This repository (`vc4-drmkms` branch) contains work-in-progress porting of the Broadcom VC4 DRMKMS driver for NetBSD.
All code generated by contributors or AI assistants MUST strictly adhere to these rules.

## 1. Coding Standards (KNF - Kernel Normal Form)
- **Tabs**: Hard tabs (8-character width) for indentation. No space indentation.
- **Line Length**: Max 80 characters per line.
- **Comments**: C-style `/* ... */` only. **NO `//` C++ style comments**.
- **Variable Declarations**: All variables MUST be declared at the top of the function/block (No mid-block declarations).

## 2. License
- New NetBSD-specific files MUST use the **BSD 2-Clause License**.
- Ported Linux files under `sys/external/bsd/drm2/dist/` MUST retain their original copyright headers.

## 3. Commit Guidelines
- Use atomic commits with `subsystem: short summary` format.
